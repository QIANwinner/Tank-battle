# QIAN 坦克大战 · Tank Battle

把经典坦克大战装进浏览器：守护基地、迎战 Boss、组合强化，打造自己的坦克。电脑和手机都能玩，无需下载或注册。

## 游戏里有什么

### 经典战斗，更多变化

保护地图底部的基地，消灭敌军并推进关卡。砖墙可以打碎，钢墙、水面和草丛改变行进路线与交战视野；油桶能引发爆炸，传送门让战场出现新的绕行机会。

普通、快速、装甲、精英、狙击、自爆、工兵等敌人各有特点，每 5 关还会迎来 Boss。护盾、快速弹、双管炮、加命、冻结和炸弹等道具，帮助你扭转局面。

### 每局构筑，跨局成长

- **局内强化**：过关后三选一，组合穿透、散射、爆破等效果。
- **长期养成**：积累金币，购买永久加成、升级基地，收集坦克与武器皮肤。
- **英雄与宠物**：搭配英雄、宠物和羁绊，尝试不同战斗组合。
- **成长记录**：挑战成就、收集关卡星级，查看生涯统计和本地战绩。

### 一个人闯关，也能一起玩

- **经典闯关**：守护基地，挑战逐渐增强的敌军与 Boss。
- **每日与每周挑战**：挑战变化的规则和目标。
- **无尽生存**：面对持续增强的敌人，冲击更高波次。
- **双人同屏**：共用一台设备，合作闯关或进行对抗。
- **自制地图**：用地图编辑器绘制地形，保存作品，并通过分享码交换关卡。

## 怎么操作

单人键盘操作：

- **W / A / S / D 或方向键**：移动，支持组合按键斜向行进。
- **空格 / J**：开火。
- **E**：释放已充能的大招。
- **P**：暂停或继续。
- **M**：切换静音。
- **F**：切换全屏，取决于浏览器支持。

双人模式：P1 使用 **WASD + 空格 / J**，P2 使用 **方向键 + 回车 / .**。

手机和平板使用虚拟摇杆移动、触屏按钮开火；其他技能与操作以游戏内提示为准。切换窗口或标签页时，游戏会自动暂停。

## 安装、离线与存档

直接打开 [在线游戏](https://qianwinner.github.io/Tank-battle/) 即可游玩。支持的浏览器还可以将游戏添加到主屏幕。

在线访问并完成资源缓存后，可以离线游玩。离线缓存依赖 Service Worker，需要通过 HTTPS 或 localhost 访问；直接双击 HTML 文件时不提供这项能力。

金币、解锁内容、设置和战绩主要保存在当前浏览器的 `localStorage` 中。更换浏览器或设备不会自动同步，清除网站数据也会清除这些记录。本地排行榜用于记录当前浏览器的战绩。

设置中提供音量、画质和减弱动效选项，可按设备性能与个人偏好调整。全屏、震动、剪贴板和安装能力因浏览器而异。

## 本地运行

游戏使用原生 **HTML / CSS / JavaScript + Canvas 2D**，运行时无需安装第三方依赖，也无需构建。

```bash
git clone https://github.com/QIANwinner/Tank-battle.git
cd Tank-battle
python -m http.server 8080
```

浏览器访问 `http://localhost:8080`。也可以直接用浏览器打开 `index.html` 体验基础游戏；检查离线功能时请使用本地服务器。

## 项目结构

```text
Tank-battle/
├── index.html              # 游戏界面、样式与核心逻辑
├── assets/                 # 独立样式与存档可靠性模块
├── sw.js                   # 离线缓存与资源更新
├── manifest.webmanifest    # PWA 应用清单
├── icon-*.png              # 应用图标
├── *.png                   # 游戏截图与展示素材
├── .github/workflows/      # GitHub Actions 工作流
├── .workbuddy/regression/  # 回归验证与截图脚本
├── RELEASE_NOTES.md        # 版本更新记录
└── LICENSE                 # MIT 许可证
```

渲染使用 Canvas 2D，音效使用 Web Audio，存档使用 localStorage。战斗核心集中在 `index.html`，样式和保存重试逻辑位于 `assets/`，适合直接阅读和修改；回归脚本的运行环境与游戏本身的零依赖运行方式分开管理。
