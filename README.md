## ✨ 特性

- 🕹️ 经典玩法：守护基地、消灭敌方坦克
- 🧱 可破坏砖墙、不可破坏钢墙、水面、草丛四种地形
- 🗺️ 5 张手写预设关卡地图循环 + 独立 Boss 场地
- 👾 4 种敌人类型：普通 / 快速 / 装甲（2 血）/ 精英（3 血）
- 📈 难度曲线：敌人速度、射速、类型比例随关卡提升
- 🎁 6 种掉落道具：护盾 / 快速弹 / 双管炮 / 加命 / 冻结 / 炸弹
- 🔥 连击评分：5 秒内连续击杀叠加 10% 加成

## 🎮 操作 - 所有按键及功能都在网页里标了哦

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / `方向键` | 移动坦克（组合按键可斜向走） |
| `空格` / `J` | 开火 |
| `P` | 暂停 / 继续 |
| `M` | 静音 / 取消静音 |

> 触屏设备左下角是虚拟摇杆（朝哪拖就往哪开，八个方位含斜向都能走），右下角是开火键（点画面任意位置也能开火），切换窗口或标签页时游戏会自动暂停。

## 🗺️ 玩法说明

- 保护地图底部中央的 **基地（鹰徽）**，基地被摧毁即游戏结束
- 消灭全部敌方坦克即可进入下一关，过关奖励 `1000 + 关卡 × 200` 分
- 共 3 条生命，重生后短暂无敌（闪烁期间子弹无法伤害你）
- 坦克无法通过砖墙、钢墙和水面；子弹可以越过水面

### 敌人类型

| 类型 | 速度 | 血量 | 得分 | 出现关卡 |
| --- | --- | --- | --- | --- |
| 普通 | 1.15 | 1 | 100 | 全程 |
| 快速 | 1.70 | 1 | 150 | 第 3 关起 |
| 装甲 | 0.90 | 2 | 200 | 第 5 关起 |
| 精英 | 1.30 | 3 | 300 | 第 7 关起 |
| 狙击 | 0.80 | 1 | 250 | 第 8 关起（远程慢弹） |
| 自爆 | 2.05 | 1 | 150 | 第 8 关起（高速冲撞） |
| 工兵 | 1.00 | 2 | 180 | 第 10 关起（修墙迂回） |

敌人速度还会随关卡整体提升（每关 +6%，封顶 1.6 倍）。

### 掉落道具

击毁敌人有 15% 概率掉落道具（Boss 必掉 3 个），走过去即可拾取：

| 道具 | 效果 |
| --- | --- |
| 🛡 护盾 | 3 秒无敌 |
| ⚡ 快速弹 | 8 秒射速翻倍 |
| ⚔ 双管炮 | 10 秒双发 |
| ❤ 加命 | 生命 +1（上限 5） |
| ❄ 冻结 | 全场敌人定身 5 秒 |
| 💣 炸弹 | 清屏（Boss 受 4 点伤害） |

### 连击与 Boss

- **连击**：5 秒内连续击杀，每层 +10% 得分；HUD 连击达 3 层变品红高亮
- **Boss**：每 5 关（第 5、10、15… 关）出现，血量 `10 + 关卡`，发射三连散弹，顶部血条显示剩余血量

## 🛠 部署与运维

- **发布流程**：改动确认后提交 `main` → 打 tag（`vX.Y.Z`）→ 推送 tag → GitHub Actions 自动构建并部署 Pages；Release 说明取 `RELEASE_NOTES.md` 对应段：`gh release create <tag> --title "<标题>" --notes-file <段文件> --target main`
- **Pages 偶发失败**：`pages-build-deployment` 偶发报 `Ensure GITHUB_TOKEN has permission "id-token: write"`（GitHub 端瞬时故障，非代码问题），直接重跑即可：`gh run rerun <run_id>`（或空提交触发重建），无需排查
- **本地预览**：任意静态服务器打开 `index.html`，如 `python -m http.server 8080`
